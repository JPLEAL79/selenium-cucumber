Execution Targets

Same framework, different Selenium Grid targets. Local is used for development; AWS is the cloud-ready path.

Local Docker Grid

Jenkins or local Maven run selects GRID_TARGET=local.
Grid URL resolves to host.docker.internal:4444 in Jenkins local.
Chrome container runs sequential UI tests.
Allure results remain local under target/allure-results.

AWS-ready Grid

Jenkins selects GRID_TARGET=aws.
Grid URL resolves to the Selenium Hub service in the AWS network.
Chrome and Firefox run in parallel branches.
Allure results can be uploaded to S3 when bucket settings are configured.

Reporting and Assisted Diagnostics

The framework enriches failures without hiding them. Diagnostics explain; humans still decide.

Evidence Collector

  • Screenshot on failure
  • Browser evidence
  • Current URL and title
  • Grid and browser metadata

Failure Classifier

  • Locator broken
  • Timeout
  • Grid or Selenium issue
  • Data/configuration issue
  • Flaky candidate

AI-ready Context

  • Compact failure payload
  • Page Object and method
  • Locator and root exception
  • Human review required
  • External provider optional
